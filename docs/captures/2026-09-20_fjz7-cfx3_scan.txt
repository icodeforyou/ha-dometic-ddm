# Observations
# - SHE_ prefix = FreshJet (app firmware id "SHE"/SHAPE), so this is the FJZ7 2600. Not a Shelly
#   (Shelly uses company id 0x0BA9).
# - The CFX3 ALSO carries Dometic company id 0x0845. Payload = 01 + a MAC-like value that
#   differs from the advertised address in the last byte (…0B F8 vs …0B FA). The doc only
#   claimed 0x0845 for DDM2 devices; classification by "CFX3" name still wins, as in the app.
# - FreshJet manufacturer payload is a single 00 byte.
# - Name suffixes (a90bf8, 366f0c) look derived from the address: CFX3 a9 0b f8 matches the
#   payload MAC bytes 4..6; FreshJet 36 6f 0c vs address 36 6F 0E (again last byte differs by 2).
